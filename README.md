# Nocturne 한국어 패치

Nocturne의 대사, 화자명, 메뉴와 텍스트 UI를 한국어로 표시하는 비공식 패치입니다.

**배포 버전: v1.0 · 적용 대상: Windows용 Nocturne 1.0.3**

[v1.0 다운로드](https://github.com/jjpatch12/nocturne-korean-patch/releases/tag/v1.0) · [패치 내역](CHANGELOG.md)

## 설치

1. 게임을 종료합니다.
2. 릴리즈 페이지에서 `Nocturne_Korean_Patch_v1.0.zip`을 내려받고 압축을 풉니다.
3. `Nocturne_한국어패치.bat`을 `Nocturne.exe`가 있는 게임 폴더에 넣고 실행합니다.
4. **1. 한국어 패치 설치**를 선택합니다.
5. 설치가 끝나면 게임을 실행하고 언어 메뉴에서 **한국어**를 선택합니다.

BAT 하나에 설치에 필요한 파일이 들어 있습니다. 별도 설치 프로그램이나 파일 다운로드는 필요하지 않습니다. 게임 폴더를 자동으로 찾지 못하면 `Nocturne.exe`가 있는 폴더의 전체 경로를 입력합니다.

## 원본 복구

게임을 종료하고 같은 BAT을 실행한 뒤 **2. 원본 복구**를 선택합니다. 변경한 게임 데이터와 한국어 패치 구성 요소를 복구하며 저장 데이터는 건드리지 않습니다.

BAT 메뉴는 설치와 원본 복구 두 가지입니다. 게임 버전과 설치 파일의 무결성을 확인하며, 파일 복사 실패 시 변경을 되돌리도록 구성했습니다.

## 한국어화 범위

| 항목 | 적용·검증 범위 |
|---|---:|
| 중앙 언어 테이블 | 9,451행 |
| 대사 클립·화자 표시 | 8,225개 |
| UI 추출 목록 | 379행 |
| 화자명 연결 목록 | 107행 |
| 추가 텍스트 직접 적용 | 3,810개 필드 |

위 수치는 서로 겹치는 목록이므로 합산하지 않습니다. 중앙 테이블의 실제 번역 문자열은 9,332행이며, 원래 빈 109행과 폰트 등 리소스 참조 10행을 보존했습니다. UI 목록의 원래 빈 2행도 보존했습니다.

대사·화자명·메인 화면·설정 등 텍스트 UI에 검수한 번역을 적용했습니다. 변수, 태그, 제어문자와 내부 화자 ID를 유지하고, 한글 폰트와 긴 문장에 필요한 대화창·선택지 배치를 조정했습니다.



## v1.0 주요 수정

- 큰 제목의 굵은 한글이 뭉개지는 현상을 줄이도록 폰트 생성 해상도와 굵기를 조정했습니다.
- 음향 설정의 항목명 시작점과 하위 항목 들여쓰기를 정렬했습니다.
- 긴 대사, 내레이션, 화자명과 선택지의 줄바꿈 및 공간을 조정했습니다.
- 메인 화면의 ‘불러오기’가 세로로 감기는 여백 문제를 수정했습니다.
